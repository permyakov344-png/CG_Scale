## Как работать с этим проектом

- **Писать пользователю по-русски**, комментировать свои действия
- Обновлять `ПРОЕКТ_СТАТУС.md` при **каждом** изменении — пользователь
  работает с проектом периодически, история переписок не сохраняется, и
  единственный способ не потерять контекст — этот файл
- Прошивка: `arduino-cli compile/upload --fqbn esp32:esp32:esp32 -p COM21`
- Диагностика: COM21 на 115200. Команда upload сама перезагружает плату;
  для ручной перезагрузки из PowerShell дёргать **только DTR**
  (RTS удерживает ESP32 в ресете)

## Подводные камни (подробности — в ПРОЕКТ_СТАТУС.md)

- Другие `.ino` в папке скетча ломают компиляцию — бэкапы хранить вне папки
- Нужен fwd-declaration `struct FixedLabel;` в начале файла
- Конструктор `Adafruit_ST7789(cs,dc,mosi,sclk,rst)` включает программный
  SPI и экран мигает — нужен 3-аргументный `(cs,dc,rst)`
- Строки для `fixed*` дополняются по **символам**, не по байтам (кириллица
  UTF-8 = 2 байта на букву)
- `#define` в Arduino действует только от места объявления и ниже
